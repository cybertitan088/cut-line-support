# CUT LINE — App Store support site

Static GitHub Pages package for CUT LINE.

Public URL target:
- Marketing: https://cybertitan088.github.io/cut-line-support/
- Support: https://cybertitan088.github.io/cut-line-support/support.html
- Privacy: https://cybertitan088.github.io/cut-line-support/privacy.html

## Publish
1. Create a PUBLIC GitHub repository named `cut-line-support` under `cybertitan088`.
2. Upload the CONTENTS of this folder to the repository root (do not upload the outer folder itself).
3. Commit/push to `main`.
4. GitHub repo → Settings → Pages → Build and deployment → Source: `GitHub Actions`.
5. Open Actions and allow the `Deploy CUT LINE support site` workflow to finish green.
6. Verify all three URLs above before entering/submitting them in App Store Connect.

The site is intentionally static, has no analytics, cookies, forms, trackers, or third-party scripts.
